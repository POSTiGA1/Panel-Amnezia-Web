# CHAT-RULES — обязательные правила для любого AI-чата в этом репо

1. Перед ЛЮБОЙ работой прочитай `HANDOFF.md` целиком — это общая память проекта между чатами.
2. Единственный источник правды о коде — **git**. Перед утверждением «в ветке X есть/нет Y» выполни `git fetch --all` и `git log --oneline -5 <ветка>`. Утверждать по памяти запрещено.
3. После каждой итерации (коммит, диагностика, инцидент, решение) — допиши запись в конец `HANDOFF.md` с датой/временем. Перед записью сделай `git pull --ff-only` (файл пишут несколько чатов).
4. Всё сделанное сразу пушится в форк: `git push origin <ветка>`.
5. Актуальные ветки: прод-панель (SERVERA, `/root/Amnezia-Web-Panel`) живёт на **deploy/v170** (с 28.09.2026; ранее deploy/v160). Ремоты локально: `origin` = форк leonidorlov-hash, `upstream` = PRVTPRO. На SERVERA наоборот: `origin` = апстрим, `fork` = форк; обновление там: `git fetch fork && git reset --hard fork/deploy/v170 && systemctl restart amnezia-panel`.
6. В HANDOFF.md никогда не пиши пароли, ключи, IP-адреса — только имена серверов и плейсхолдеры `<IP:ИМЯ>`.
7. Команды для серверов давай пользователю по одной — он выполняет их вручную.
